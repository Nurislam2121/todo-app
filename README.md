# Список задач

Тестовое задание ZalogHub (Junior Frontend Developer): список задач на React + TypeScript, проект создан на Vite.

## Возможности

- добавление задачи через поле ввода и кнопку (также по Enter);
- пустую задачу или задачу из одних пробелов добавить нельзя — кнопка неактивна;
- переключение задачи между выполненной и невыполненной (выполненные зачёркнуты и приглушены);
- удаление задачи;
- фильтры: все / активные / выполненные;
- сохранение в `localStorage` — задачи остаются после обновления страницы.

## Запуск

Нужен Node.js 18+.

```bash
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Сборка и проверка типов:

```bash
npm run build
npm run preview
```

## Структура

```
src/
  App.tsx                  # состояние, фильтрация, сборка интерфейса
  types.ts                 # типы Todo и Filter
  hooks/useLocalStorage.ts # состояние с синхронизацией в localStorage
  components/              # TodoForm, TodoFilters, TodoItem
  index.css                # стили
```

## Примечания

- Данные из `localStorage` проверяются при чтении: если там повреждённый JSON или неожиданный формат, приложение стартует с пустым списком.
- Без внешних библиотек, кроме React.

## Затраченное время

Примерно 1,5 час (80-90 минут).
